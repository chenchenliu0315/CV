# Interactive Resume Project

This project is an interactive personal resume webpage designed with a clean and modern aesthetic. It features various sections to showcase personal information, skills, work experience, project highlights, and contact details. The webpage is built to provide a smooth user experience with engaging animations and responsive design.

## Project Structure

```
interactive-resume
├── index.html         # Main HTML file for the interactive resume
├── README.md          # Documentation for the project
├── css
│   ├── reset.css      # CSS reset styles for consistent look across browsers
│   └── style.css      # Main styles for layout, color scheme, and typography
├── js
│   ├── main.js        # Primary JavaScript for functionality and event handling
│   └── animations.js   # JavaScript for scroll animations and transitions
└── assets
    └── fonts          # Directory containing font files for the project
```

## Features

- **Personal Information**: A dedicated section to present your name, title, and a brief introduction.
- **Skills**: A visually appealing display of your key skills and areas of expertise.
- **Work Experience**: A chronological list of your professional experiences, highlighting roles and responsibilities.
- **Project Showcase**: A gallery of projects you have worked on, with descriptions and links.
- **Contact Information**: Easy access to your email and social media links for potential employers or collaborators.

## Setup Instructions

1. Clone the repository to your local machine:
   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:
   ```
   cd interactive-resume
   ```

3. Open `index.html` in your web browser to view the interactive resume.

## Usage

- The webpage is designed to be responsive, ensuring a seamless experience on both desktop and mobile devices.
- Hover effects and scroll animations enhance user interaction and engagement.
